Slack Thread Merger

Insert Slack reply threads back into a channel export at the right points, and get one tidy markdown file out.

1. Channel export

The main Slack channel markdown (e.g. sample-input.md). Upload a file or paste the text.

…or paste channel text

⚠ Pasting raw text straight from Slack will not format nicely — the sample files have already been processed.

2. Reply thread files

Select all the reply-thread markdown files (e.g. the 28 ReplyThreadNN.md files). Each is matched to its insertion point by the number in its filename, falling back to order if a number is missing.

Result

Runs entirely in your browser. Nothing is uploaded anywhere.
